# Loreweaver 路线图

Loreweaver 年轻，主要由一个人在 AI 协助下开发。这是诚实的前进计划——项目当前的重心、之后的更大方向，以及一个曾经摆在台面上、现在已经拍板的设计分歧。层级契约与铁律见 [AGENTS.md](../AGENTS.md)。

## 志向

Loreweaver 的目标不是“用 AI 替代一个跑团主持人”，而是做 **AI RPG 的引擎与开放标准**。强大的 coding agent 已经很多，合格的 RPG agent 却太少；而一个世界要能被带走、被续写、被别人的程序读懂，所需要的格式根本还不存在。这里的每一层——真骰子和硬规则、靠工具调用行事的守秘人、只知道自己该知道的事的子角色、照 SKILL.md 与酒馆规范生长的扩展生态——都朝同一个方向：让“跑好一个世界”成为 agent 的一等能力，而且跑在谁都不用申请许可的格式上。

## 现状

确定性引擎——骰子、检定梯子、角色数学、规则校验、游戏时钟——是稳固的核心，由一整套确定性离线测试覆盖。**终端 OpenTUI 仍是主要客户端**，经 **Iroh** p2p 连接。聊天平台适配器（Discord/QQ/Telegram/飞书/OneBot）已于 2026-07-30 **主动移除**：项目的 UI 方向——声明式 `ui` 帧、实时追踪面板、深度可定制的客户端扩展层——是纯文本聊天平台在结构上就渲染不了的东西，客户端一律改走开放协议。

**v1.0.0 已作为第一个稳定版发布**，之后继续在 `1.0.1.dev*` 线上开发。这期间落地了四个结构性里程碑：

- **规则变成了数据（M16）。** 一个规则系统就是一个文件，它自己拥有检定梯子、卡表形状、子系统、点命令方言和守秘人须知。引擎不再知道 CoC 是什么：架构测试把 `agent/` 钉死在零规则系统词汇上，删掉 `rulepacks/coc7.yaml`，CoC 就干净消失、不留残渣。DSL 表达不了的系统落到沙箱纯函数通道。
- **一个文档模型（M17）。** 房间里的一切内容——设定、NPC、卡表、预设角色、追踪器、笔记、知识池——都是同一个 `Document` 类型，而每种类型的 `project(document, viewer)` 就是信息隔离唯一的出线口。五套并行的保密机制合成了一套，每一份按存储分列的备份白名单（漂移 bug 的稳定来源）也随之消失。
- **能撑过上下文窗口的长团记忆（M18）。** 跑团过程被记成编年史文档，按确定性策略折叠进滚动摘要，于是一场战役可以比它的上下文窗口活得更久。`.recap` 是同一批文档面向玩家的投影。
- **演出层（M19）。** 演出导演——一个玩家侧、知识受限的演员——在剧情节拍上用声明式演出模板、音频提示和带定妆约束的生成图来做舞台，剧本则是模组作者随包发的一份创作简报。协议 2.1。

在这些之上：确定性模组变量与实时追踪面板、导入酒馆卡的完整兼容（MVU 变量树、`<UpdateVariable>` 文本协议、QuickJS 沙箱里的完整 EJS、酒馆世界书触发语义）、能画声明式 UI 的沙箱事件钩子、走 Git Release 分发的 `.lwpack` 内容包，以及发布在 npm 的协议 SDK（`loreweaver-protocol`，其 `major.minor` 跟随协议版本）。再往上是**拆卡**：导入会把一张酒馆卡拆成人物半（玩家可自带，机制被结构性剥离）和世界半（仅守秘人的 `.import … world`）；内容包给卡标注 `world` / `character`，标签由真实检测强制；导入的变量树默认不上玩家面板，由守秘人逐路径公开；模组还能以规则包*补丁*（`extends: coc7` + 增量）的形式携带自己的规则。细节见 [plugins.md](plugins.md)、[cards.zh.md](cards.zh.md)、[hooks.zh.md](hooks.zh.md)。

## 基础设施——已完成

硬化工作刚刚落地了那些在添加广度前必须正确处理的不起眼的东西——该项目现在可以干净安装、行为正确，对小群体的运行也更安全：

- **可安装性。** Wheel 包含每个软件包和运行时数据（本地化、规则包），所以 `pip install` 可以在干净的环境中工作——而不仅限于源代码签出。
- **权限模型。** 玩家/守秘人区分现在在*每个*命令表面执行（之前仅在管理框架上保持——玩家密钥可以通过终端运行守秘人专用命令）。暴露秘密的回复——掩盖的 API 密钥、守秘人专用的传说——仅限于调用者，不向房间广播。
- **角色正确性。** 编辑技能/属性不再治疗受伤的调查员，创建派生正确的起始生命值（满血/满魔力、SAN = min(POW, SANMAX)）；每个属性设置路径都被限制在规则包范围内。
- **诚实的审核。** 内容过滤器默认关闭且无捆绑词表（可配置），文档明确说明这一点，而不是暗示内置审核。
- **真实模型红线门控。** 每晚作业让真实模型跑过 turn pipeline，按守秘人秘密的逐字/转述哨兵测量**泄漏率**，并统计**骰子优先漏骰率**，超阈值就失败。它只是一组特定模型、特定运行的回归信号，不是永久保证。（为什么必须与离线套件分开，见[下文](#离线测试-vs-真实模型质量)。）
- **传输与发布内务。** Iroh join 超时、按房间约束的 Keeper key 管理、受支持系统上的 owner-only 本地敏感文件权限、带摘要校验的发布包、稳定版/pre-release 分流、Python 3.11/3.12 CI，以及死代码清理。
- **聊天适配器——建成，然后退役。** 五个 Mock 测试覆盖的平台适配器（Discord、QQ 官方、Telegram、飞书、OneBot 11）被硬化到相当可用的程度之后被主动删除：UI 拓展方向（声明式帧、模组自绘面板）让纯文本渲染成了死胡同，与其永远端着一个二等体验，不如诚实地下线。它们验证过的跨端 RoomHub 机制保留了下来，继续支撑 CLI 与协议客户端。

## 近期

- **多人游戏抛光。** 既然权限模型已执行，收紧其余网络游玩的粗糙边角（真正的机器人循环守秘人、更丰富的迟到加入者状态），使可信人员之间的房间真正舒适。
- **配套客户端与制卡工作台。** 创作侧——不用手写 JSON 就能做 Loreweaver 原生卡和内容——在 [loreweaver-studio](https://github.com/1A7432/loreweaver-studio)，已经公开：十一步向导、面向酒馆发布的 SillyTavern 导出、以及预设导入镜像。它比本仓库更早期，正在追赶 2.x 的各项格式。
- **一个旗舰模组。** 格式的价值等于第一个认真用它做出来的东西。旗舰模组正在做，并且是和面板/演出层一起共同设计的——让这一层有真实的第一个消费者，而不是一个假想的。

## 更大方向——世界引擎

差异化因素是冒险*下方*的世界，而不仅仅是带骰子的聊天。长期方向：

- **高度可定制的 UI 拓展层。** 砍掉聊天适配器的原因：模组和钩子应该能**画出自己的界面**——今天是声明式 `ui` 帧（进度条、徽章、选项按钮），接下来是更丰富的模组自定义面板与客户端侧拓展点——让一个世界不只带规则和设定，还带自己的桌面陈设。渲染目标是协议客户端（TUI 与配套桌面客户端）。
- **更深世界书：** 生成型世界（不仅仅是关键字/向量检索传说）、**活生生的因果时间线**，其中事件有后果传播、**规范一致性**使守秘人无法矛盾既定事实。
- **迟到加入者赶上：** 在活动中期加入的玩家被赶上他们角色*应该*知道的信息——而不泄漏他们不应该知道的。
- **D&D Beyond 角色单导入**，与现有的 SillyTavern 卡路径并排。
- **扩大预编译平台覆盖**，超过当前的 Windows x64、macOS arm64、Linux x64/arm64 矩阵。

## 一个我们已经关掉的问题

**守秘人的秘密该放在哪？** 这件事一度是个真分叉。守秘人的系统提示里接近完整地带着模组的守秘人池，守秘人专用工具也把秘密原样交回模型——所以在守秘人这一侧，反元游戏靠的是*纪律*（一条“别把这些引给玩家”的指令），而不是结构保证。另一条路是把秘密从基础提示里拿掉，让守秘人按需用工具取，模型任何时刻只握着它刚推理过的那一条。

**我们决定不走那条路。** 一个不掌握全部真相的守秘人，主持不了一个谜：它埋不了伏笔，把握不了揭示的节奏，两次跑团之后就会自相矛盾。给守秘人自己的知识分级，是拿产品的立身之本去换一点泄漏面——而泄漏面本来就该由行为评测来管。所以这条线是**永久的、也是刻意的**：

- **对其他所有人，是结构保证。** 玩家、NPC、同伴、演出导演拿到的只有投影，别的什么都没有。这由构造保证，并有哨兵测试盯着。
- **对守秘人本人，是行为约束。** 它看得见模组，它被要求不许引用。这条要求是被*度量*的——每晚拿真模型跑一遍——而不是被当成保证宣称的。

诚实的说法就是 README 和 [deploy.zh.md](deploy.zh.md) 里那一句，并且会一直留在那儿：CI 绿，说明的是引擎正确，不是守秘人嘴严。

## 离线测试 vs. 真实模型质量

值得明确说明，因为绿色 CI 容易被过度阅读：离线套件是确定性的，使用*脚本化*守秘人。它严格证明确定性机制——守秘人/玩家知识编辑、子行为体提示隔离、真实种子骰子、命令表面——它会捕捉这些中任何一个的回归。它**不能**证明实时模型避免泄漏显示给它的秘密，或它投掷后叙述；那些是模型行为属性，它们正是真实模型红线门（现在每晚运行）存在以测量的。读取“CI 绿色”为*引擎正确*，不是*守秘人好*。
